# پلتفرم جامع موسیقی «آهنگام» (Ahangam)

سامانه جامع، مدرن و حرفه‌ای پخش آنلاین و دانلود موسیقی طراحی و پیاده‌سازی شده مطابق با سند پروپوزال جامع **آهنگام**.

---

## 🌟 ویژگی‌ها و امکانات پیاده‌سازی شده

### ۱. معماری و فناوری‌ها
- **فریم‌ورک:** Next.js 15 (App Router) با تایپ‌اسکریپت (TypeScript)
- **پایگاه داده و ORM:** Prisma ORM با پایگاه داده رابطه‌ای محلی (SQLite / قابلیت سوییچ به PostgreSQL)
- **طراحی و تم:** Tailwind CSS با توکن‌های طراحی پویا (CSS Variables)، پشتیبانی کامل از RTL و فونت‌های فارسی
- **احراز هویت امن:** هش یک‌طرفه رمز عبور با Bcrypt و مدیریت توکن‌های نشست مبتنی بر Cookie امن (HTTP-only)

### ۲. سیستم تم و هویت بصری
- **تم پیش‌فرض:** بنفش مدرن و جذاب (`#7c3aed`) طبق پروپوزال
- **انتخابگر زنده تم:** پشتیبانی از ۷ پالت رنگی (بنفش مدرن، آبی اقیانوسی، سبز زمردی، فیروزه‌ای، صورتی نئونی، قرمز یاقوتی، نارنجی غروب)
- **حالت‌های روشنایی:** حالت تاریک (Dark Mode)، حالت روشن (Light Mode) و حالت خودکار (System)
- پیش‌نمایش آنی تغییر تم و ذخیره‌سازی ترجیحات کاربر

### ۳. اولویت موبایل و پخش‌کننده حرفه‌ای صوتی (Music Player)
- **Mini Player شناور:** در پایین صفحه با نوار پیشرفت، دکمه‌های کنترل، نمایش کاور، عنوان و هنرمند و حفظ وضعیت هنگام جابه‌جایی در صفحات
- **Full Player تمام‌صفحه:**
  - متن همگام‌سازی شده ترانه (Synced / Timed Lyrics) با اسکرول خودکار به خط فعال و کلیک برای رفتن به زمان مشخص
  - مدیریت صف پخش (Queue) با امکان حذف و جابه‌جایی
  - سوییچ کیفیت واقعی (128kbps, 320kbps, FLAC)
  - تایمر خواب (Sleep Timer: ۱۵، ۳۰، ۴۵، ۶۰ دقیقه)
  - حالت صرفه‌جویی در مصرف اینترنت (Data Saver)
  - پخش تصادفی (Shuffle) و تکرار قطعه/صف (Repeat)

### ۴. سیستم استوری تعاملی (Stories Tray)
- نوار استوری در بالای صفحه اصلی با حلقه‌های گرادیان نئونی
- مودال استوری با نوارهای تایمر پیشرفت، مکث با نگه‌داشتن دست/موس، و دکمه اتصال مستقیم به اثر یا هنرمند
- مدیریت کامل استوری‌ها از پنل مدیریت

### ۵. پلی‌لیست‌های اختصاصی و علاقه‌مندی‌ها
- **علاقه‌مندی‌ها (Favorites):** کلیک بر روی آیکون قلب در صفحات آهنگ و ذخیره‌سازی در دیتابیس با بازتاب آنی در بخش «کتابخانه من»
- **ساخت پلی‌لیست شخصی (`/playlists` و `/playlist/[slug]`):** امکان ایجاد پلی‌لیست‌های نامحدود توسط کاربران، افزودن قطعات دلخواه و پخش یک‌جای تمام آهنگ‌های پلی‌لیست

### ۶. سئو و موتورهای جستجو (SEO)
- **نقشه سایت پویا (`/sitemap.xml`):** تولید خودکار نقشه سایت شامل تمام آهنگ‌ها، هنرمندان، آلبوم‌ها و صفحات ثابت
- **فایل راهنمای خزنده‌ها (`/robots.txt`):** باز بودن صفحات عمومی و مسدودسازی دسترسی خزنده‌ها به پنل مدیریت و API
- **تگ‌های متای معنایی و OpenGraph:** تنظیم تگ‌های اشتراک‌گذاری در شبکه‌های اجتماعی

### ۷. پنل مدیریت تکمیلی (`/admin`)
- **مدیریت تیکت‌های پشتیبانی (`/admin/tickets`):** مشاهده پیام‌های دریافتی از فرم تماس با ما، پاسخ‌دهی آنلاین مدیریت به پیام‌ها و تغییر وضعیت تیکت (باز، در حال بررسی، حل شده، بسته)
- **نظارت بر دیدگاه‌ها (`/admin/comments`):** تایید، رد یا حذف دیدگاه‌های ارسالی کاربران زیر هر قطعه موسیقی
- **مدیریت کاربران، هنرمندان، آلبوم‌ها، استوری‌ها و تنظیمات ظاهر**

### ۷. پنل مدیریت جامع و قدرتمند (`/admin`)
- **داشبورد تحلیلی واقعی:** بدون ارقام ساختگی؛ نمایش مجموع کاربران، اعضای VIP، قطعات، پخش‌ها، دانلودها و گزارش‌ها
- **فرم حرفه‌ای افزودن آهنگ:** بارگذاری فایل صوتی، تشخیص خودکار نام و مدت زمان، ثبت لینک‌های کیفیت‌های مختلف، متن ترانه، لیریکس همگام، عوامل تولید، پیش‌نویس/انتشار فوری، و پیش‌نمایش در ابعاد موبایل
- **مدیریت هنرمندان، آلبوم‌ها و استوری‌ها**
- **مدیریت کاربران و زیرادمین‌ها:** تعیین نقش‌های USER, VIP, ADMIN, SUPER_ADMIN، تعریف دسترسی‌های محدود و مسدودسازی حساب
- **مدیریت محتوا و ظاهر:** ویرایش متون سایت، نام هنرمند پیش‌فرض، قوانین دانلود و پالت‌های رنگی بدون دستکاری کد

## 🚀 نحوه راه‌اندازی و اجرا

### ۱. اجرای سرور توسعه:
```bash
npm run dev
```
سپس آدرس `http://localhost:3000` را در مرورگر باز کنید.

### ۲. ساخت نسخه نهایی و اجرا در محیط Production:
```bash
npm run build
npm start
```

### ۳. همگام‌سازی یا پر کردن مجدد داده‌های آزمایشی پایگاه داده:
```bash
npm run db:push
npm run db:seed
```

### ۴. مشاهده بصری داده‌ها با Prisma Studio:
```bash
npx prisma studio
```
